License: SIL Open Font License 1.1; see BarlowCondensed-OFL.txt in this folder.
Generated by tools/migration/import-ui-source.py from the existing H5 asset
shared/fonts/BarlowCondensed-BoldItalic.ttf.

Modification: the Unicode digit mappings use the original font's OpenType
tnum glyphs (zero.tf through nine.tf), and the family/full/PostScript names
have been changed. Glyph outlines and advance widths have not been redrawn.
This implements the H5 CSS tabular-nums selectors in NanoVG, whose current
Lua API does not expose OpenType feature selection. Other UI text uses the
unmodified source font. Source and output hashes are recorded in
docs/migration/evidence/ui-tabular-font.json.
