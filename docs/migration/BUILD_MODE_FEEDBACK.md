## 来源与实现

原 `shared/ui/ui.js` 的 `_modeBadge`、`style.css` 与最终 `new-ui-utility.css` 为来源。`measure-source-build-modes.cjs` 在原 H5 浏览器中切换工具并读取 computed style，报告为 `evidence/source-build-modes.json`，包含 PC、16:10、20:9 横屏和 4:3 横屏。

- 顶部模式条：逻辑坐标 top=72，height=38，居中；实底 `#172e45`、右上 12px 切角、左侧 3px 工具色条。普通放置隐藏，显示上色、删除、选择及粘贴的源文字与源图标。
- 上色显示主色/装饰色、实际颜色及名称、Tab 切换提示和 P/Esc 退出提示；原色为 `#c9ced6`。选区数量、复制粘贴状态随真实编辑器变化。
- 原曲线：opacity `.2s ease`、位移 `.25s cubic-bezier(.16,1,.3,1)`、工具/通道变化 `.3s cubic-bezier(.34,1.56,.64,1)`，scale 从 .86 到 1。变更颜色不重复触发工具弹跳。
- 准星普通中心 4px，上色 10px，删除/选择 6px；工具色及黑色衬边来自原版。准星保持 CSS 屏幕像素大小，模式条随整套参考分辨率缩放。
- 原 computed style 的提示栏仍为 top=76，并没有工具状态下下移的最终覆盖规则，因此不自行改变其位置。
- Esc 先释放鼠标，再依次取消粘贴、清空选择、退出当前工具，最后才打开暂停。Tab/P/X 退出选择工具后切换对应工具，防止选取状态与模式条冲突。

`ui/BuildModeBadge.lua` 是现有 UI 的 Panel 子类，不单独创建 NanoVG 上下文、字体、渲染目标或事件订阅。内容和字框在工具/通道/配色/选区变化时重新生成，稳定帧复用。正文的两个静态宽度从原 H5 输出到 `UI/SourceBuildModeLayout.json`，避免 Web 备用字体使整条布局变短；保留备用字体的实际绘制，不把布局相同称为字形栅格相同。
