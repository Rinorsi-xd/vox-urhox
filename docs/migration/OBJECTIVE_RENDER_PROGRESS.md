# 占点与推车场景表现

冻结源 `2b169a9964645f5f346a7158bcb14447f040814a` 的 `three/src/battle/matchView.js`。

本批修复：占点半径22米、3米高光墙、地面填充0.2米/外圈0.25米/进度0.3米分层，96/48段几何；光柱淡出按相机水平距离35..95米。地面圈和进度、推车范围圈按源有意穿透；墙/填充/柱仍需深度测试。独立ObjectiveOverlay shader隔开材质，局部节点分别拥有bounds，以便引擎视锥剔除。

推车橙色路线和30米检查点柱改成加载时一次建好，各段独立bounds，不再每10Hz整条重建。3米虚线/2米间隔按3D弧长连续；检查点节点索引继续使用玩法原cum，不改移动路线。颜色按Three十六进制sRGB转线性。反应堆暴露橙闪和0.4rad/s轨道已补。

`tools/migration/check-objective-geometry.lua` 11项PASS：真实Lua生产几何、3-4-5斜坡虚线、连续相位、检查点定位/封口、范围圈overlay、近处光柱隐藏、墙尺寸与释放。Node/材质是适配器，不能签像素/深度/运行性能。g4独立源核对确认镜像、墙尺寸与overlay拆分，指出3D虚线问题后已修。

待验：统一Web两模式实际入口/深度像素、反应堆受击闪白和随机抖动、路线1px屏幕宽度（当前0.12米世界宽度）、所有相机比例。未实现地理流式卸载，未签软件遮挡剔除收益。
