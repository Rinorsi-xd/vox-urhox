# 节足移动迁移（2026-10-06）

按源项目 2026-10-05 重写的 LegController / LegGait 接入同一 TrialSession。六足 T3/T5、密集十足 T5 均来自原项目验收蓝图；沿用已转换的真实分段模型，没有另做占位造型。源项目只读。

## 使用

```powershell
./preview-hangar.ps1 -Trial -Blueprint LegT3 -Quality mobile
```

可替换为 LegT5 / LegWaveT5。W/S 前后、A/D 转向、Q/E 横移、Space 跳跃、R 复位、N 切换区域、T 返回大厅。触控区提供跳跃和横移，松开、移出、取消立即释放。蓝图未装武器，因此不能开火；完整建造/车位选择 GUI 后续迁移。

## 职责与资源

- `drive/LegControl.lua`：60 Hz 支撑射线、弹簧阻尼、斜坡/墙面法线、牵引、转向、跳跃与吸附，只施力/冲量，不直接摆正车体。
- `drive/LegGait.lua`：交替三足与密集行波步态、预判落点、着地锁脚、邻足间距、最大 3.8 Hz 步频。支撑与脚动画独立。
- `parts/LegIK.lua`：同一套源 IK、可达性限制和关节点坐标。
- `drive/LegHitboxes.lua`：每条腿四个无质量解析盒，逐固定步跟随关节；失效当前受击 broadphase 缓存。不会增加物理支撑或与地面碰撞。
- `render/LegView.lua`：在插值后的实际 PartRig 层级内反解世界落点，显示不改物理。模型和材质继续共享；不加载其他未使用档位的网格。
- `app/TrialSession.lua`：节足视角通过 ThirdPersonCamera 跟随插值后的车身中心，避免爬墙后沿用平地高度偏移而裁掉车体；轮式和飞行视角沿用原规则。
- 删除原先 Vehicle.New 的“节足未迁移”拒绝分支。损伤重建按 partId 恢复存活脚状态，移除的脚和原生刚体释放；退出试车沿用既有场景销毁流程。

支撑只抓静态地形，排除自身、车辆、碎片、运动学刚体和传感器。至少四条可用腿、节足为主且未超载才有爬墙能力；否则使用原版 40° 坡度规则。三条腿不能跳跃。失去地形支撑会真实下落。

## 原版对照与原生验收

```powershell
./tools/migration/verify-leg-drive.ps1
./tools/migration/verify-leg-trial.ps1 -Blueprint LegT3 -Screenshot
./tools/migration/verify-leg-trial.ps1 -Blueprint LegT5 -Screenshot
./tools/migration/verify-leg-trial.ps1 -Blueprint LegWaveT5 -Screenshot
```

源数据生成器只导入原项目模块，所有产物写入本工程 tools / assets。5340 步来自 14 段实际 Rapier 轨迹，涵盖平地、坡、墙、跳墙、原地转向、启停和十足行波。Lua 重放同样的刚体状态、射线结果和点速度，逐步比较射线调用、支撑/牵引/跳跃力、遥测、步态时钟和各脚目标。点速度及跳跃后的即时速度取原生记录，避免把 Rapier float32 与 Lua double 的差别当成控制算法差异。

另外用原版 LegHitboxes 类生成 89 组关节碰撞盒，比较各段中心、半尺寸、旋转和部件 ID。数据保存源码 SHA256 以标识测试来源。它们位于非资源根 tools 下，不进入游戏包。

控制与原生验收 **142 项通过**，其中每段源轨迹是一项聚合断言，内部逐步检查，不是只比最后一帧。原生独立检查结果：

| 场景 | 结果 |
|---|---|
| 六足 T3/T5、十足 T5 | 中立静止、前进、松开减速、横移、转向、跳跃、落地通过 |
| 直线行走 | 连续着地脚最大位移 0 m；T3/T5 各记录 498 个 swing 帧，十足 830 个 |
| 起跳净上升 | T3 约 3.03 m；T5 / 十足 T5 约 5.01 m |
| 原版墙体 | T3 质心最高 8.27 m，出现实际爬墙状态并越顶 |
| 原版山坡 | T3 质心最高 11.28 m |
| 跳墙 | 起跳后重新吸附，质心最高 7.93 m |
| 边界 | 越出有限地形下落；缺腿禁跳/禁爬；超载禁爬；动态/运动学物件不作为支撑 |

同一应用 mobile 档 T3、T5、十足 T5 各 **26 项通过**：真实脚尖插值、当前刀足命中 ID、断腿重建、存活落点保留、触控释放、回机库销毁和相机中心。额外墙面截图检查为 **27 项**，要求车身实际倾转、质心高于 3 m，同时处于攀爬状态。T3 平地 414 个着地脚插值采样最大误差约 0.000008 m，关节传感器中心与原生层级位置误差同量级。

回归：地面驾驶 22 项、悬浮/飞行 651 项、移动档试车往返 34 项、战斗 92 项、靶车破坏 7918 项通过，无 Lua/资源错误。报告在 `evidence/leg-drive.json`、`leg-drive-measurements.json`、`leg-trial-*.json`；`leg-drive-states.png` 是受控状态对照图，各格为独立运行的截图，不是连续录像。

## 明确边界

Bullet 的碰撞、质心与惯量仍与 Rapier 不同；源控制重放一致不代表完整原生轨迹一致。墙/坡原生验收目前针对 T3，T5/十足已验证平地、跳跃与关节；未穷尽混装、旋转安装和复杂狭缝。

保留源 legRig 的空中/无落点回到建模休息姿态规则；源控制器空中目标仍驱动命中盒。这意味着空中展示与传感器存在原版已有的姿态差异。本轮像素位置验证针对着地支撑状态，不能推广成所有空中关节都完全吻合。跳跃发光和真实落脚接触环已接入，见 EQUIPMENT_EFFECTS.md；原版接触效果不是粒子。

未操作用户编辑器；原生崩溃根因仍未确认。当前 mobile 档是在电脑上执行，尚不证明骁龙 845 持续帧率/温度达标；远端下载、弱网缓存和完整 GUI 仍未验收。物理模块修改需要重启预览，不承诺对当前运动状态做任意热替换。
