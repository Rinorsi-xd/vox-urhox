# 试车场交互射击迁移（2026-10-05）

同一 TrialSession 已接入真实武器、场地射线、靶板伤害与初步战斗特效。没有新的游戏入口，也没有改写源项目。

## 运行与职责

- `main.lua` → `HangarApp` → 按需加载 `TrialSession`。大厅启动不创建战斗批次；离开试车场销毁它们。
- 固定步长顺序：Vehicle → WeaponSystem → 立即消费本步事件 → TrackWorld → 保存姿态。每个 30 Hz 画面对应两个 60 Hz 模拟步，不能只消费最后一步的事件数组。
- 相机中心射线排除自身车体；枪口另做真实射线/弹丸扫掠。两条射线分别处理第三人称相机与枪口的遮挡，显示层不决定命中。
- `TrackWorld` 负责目标生命、4 秒复位、移动靶和锥桶冲量；`TargetFeedback` 负责受击发光、倒下动画后的血条显示。靶板死亡立即退出物理射线。
- `WeaponView` 读取模拟角度和转管状态；`CombatEffects` 消费 shot/beam/impact/dry 及 break/explode 事件。靶车逐零件损伤、穿透、脱落、残骸和重生见 [破坏迁移](DESTRUCTION_MIGRATION.md)。
- 视角不会自动拉回车头而打断瞄准。右键拖动或触屏拖动调整视角，C 回正；左键点击游戏区域/按住开火按钮射击，Tab 或 1/2/3 选择已安装的武器组。
- 游戏区域的指针处理面板位于 HUD 后面，按钮事件不会通过全局鼠标轮询触发射击。释放、移出、取消、失焦、复位、返回都会清除对应状态。触屏拖动本身不射击，另按开火按钮。

## 特效来源与预算

依据源 `three/src/drive/weaponFx.js`、`effects.js`、`fx/ribbons.js`、`streaks.js`、`glows.js` 移植：金色能量弹的多层光点和水滴弹身、枪口火舌、蓝色激光、狙击白芯/色晕/螺旋、电弧、冲击环、命中火花、烟和哑火反馈。原有程序化公式转换为 SurfaceShader，无新增 AI 图片。

| 预算 | desktop | mobile |
|---|---:|---:|
| 光条段 | 2400 | 640 |
| 能量弹/火舌条 | 1000 | 240 |
| 发光片 | 2200 | 640 |
| 火花 | 1000 | 240 |
| 烟 | 240 | 64 |
| 冲击环 | 40 | 40 |
| 单条螺旋段 | 300 | 96 |
| 破坏视觉碎屑 | 360 | 96 |

光条、光点、烟和环每类一个 CustomGeometry/材质、每帧一次提交，空批次禁用；破坏碎屑使用惰性创建的共享模型/材质实例池。RGB 以 1/16 存入归一化顶点色，shader 恢复 HDR，避免原版大于 1 的颜色被截断。超出容量只丢弃视觉细节，不丢失战斗判定。血条独立一个批次；靶面共用一个材质，受击亮度通过实例参数传递。

这些上限不是零分配或手机性能保证：Lua 目前仍会构建临时向量/顶点，较多螺旋时有 CPU 上传开销。后续真实设备测量再决定是否改为原生顶点缓冲或进一步简化远处特效。

## 验收

`tools/migration/verify-combat.ps1 -Screenshot` 与 `-Quality mobile -Screenshot` 各通过 92 项检查，零脚本/资源/引擎错误。使用隐藏的独立 Runtime，不操作桌面编辑器。大厅生命周期回归 12 项通过。检查包括：

- 12 种武器在原生场地内真实扣血，伤害值与已有源模拟参数一致。
- 激光/机枪/狙击被中间墙挡住，相机中心命中正确，射线排除自身车体。
- 目标死亡、重复伤害不重复计数、碰撞移除、4 秒后满血复位、移动靶碰撞更新、动态锥桶冲量。
- 默认赛车实装机枪/狙击、30 Hz 多步事件消费、能量停机/恢复、武器关节更新。
- 指针回调与同时左右键释放状态；触屏拖动与射击分离，复位取消飞行弹丸。
- 瞬时大量射击事件的容量限制、过期后空批次、特效不修改伤害统计、返回大厅释放。

这是原生物理/渲染加输入回调回放；不是已完成真人鼠标/手机多指操作或编辑器 Play 压力验收。截图中使用固定目标坐标和冻结模拟帧，便于重复比较枪口与命中效果。`-Phase late/clear -Screenshot` 分别观察衰减及清空状态。

## 尚未完成

枪身机械动作、能量流、能量环/漩涡/粒子/轨道电弧及停机/上线效果已补齐，见 [武器显示迁移](WEAPON_PRESENTATION.md)。仍缺原版瞬时点光、部分 T5 弹道二次电弧、表面微纹理、声音与镜头震动；核心建造交互、完整 GUI 与伤害统计界面。当前烟粒子未做深度排序，交叠混合仍有差异。

本机 mobile 档不等于骁龙 845 真机测试。远程下载表现、持续帧率/温度、编辑器原生崩溃根因仍未验收。本轮结果不能据此宣称整个迁移完成。
