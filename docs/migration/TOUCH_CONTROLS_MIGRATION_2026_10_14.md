# 原版触控 UI 与输入迁移

## 来源与范围

来源为 H5 分支 `2026-10-13`、提交 `90862445074e7e146da900037979ad97899ecf6c`，只读取 `.tmp/outgame-source-2026-10-12T21-18-23-463Z`。目标分支 `codex/h5-2026-10-13`。依据 `shared/controls/touchControls.js`、`shared/css/touch-controls.css` 和 `shared/build/editor.js` 的实际行为，排除无尽模式。

原版 `editor.js` 明确建造只有第一人称，触屏也调用 `rig.setMode('fp')`。本批撤掉迁移端手机建造的环绕相机，使用已有第一人称飞行、场景限制和中心拾取。没有改 PC 的既有按键方案，没有调整场景光照。

## 实际接入

- 原触控按钮渐变、顶部内阴影、落影、青色边框、按住/开镜高亮、摇杆及菜单；独立 CSS 像素尺寸，不随驾驶 HUD 的参考分辨率放大。
- 菜单采用原三列选项、真实滚动与“更多建造操作”折叠项；折叠项恢复透明背景和展开标记。保留原文案与操作次序。
- 原按钮最终高度为 48 CSS px：`#touch-controls .tc-actions button` 的优先级覆盖 `.tc-primary` 的 64px 声明。以浏览器 computed style 为准。
- 摇杆保留 0.12 死区与模拟量；低功率输入不再被飞行相机归一化成全速。驾驶与建造支持一指移动、一指转向，开火按钮可按住拖动瞄准。
- 驾驶双指缩放直接传 CSS delta，独立于桌面滚轮单位转换。建造源模式是 FP，因此不擅自增加建造双指缩放。
- 建造中心操作、300ms 首次重复与 100ms 连续操作、选择拖动、取消不提交，以及原保存、零件库、工具、镜像、复制粘贴、移动选区等命令。
- 驾驶换武器、翻正、辅助动作分配、步进转轴、竞技战绩与返回；触控调用现有玩法接口，不模拟全局键盘事件。
- 按触点保存所有权；松开开火保留摇杆，取消不触发短按开镜。菜单、失焦、窗口变化、弹窗与退出会释放持有状态。

## 验证方法

`measure-source-touch.cjs` 在浏览器实例化冻结源的真实 `TouchControls`，加载真实 CSS，隔离场景采集矩形和最终样式。四个布局为 840×378、800×450、1024×768、640×320；另采集 201 个原摇杆输入和原 pinch/开火拖瞄样本。此夹具证明源触控层，不代表完整源场景截图对照。

原生 `check-touch-controls` 1158/1158，通过源输入数值、布局/DPR、真实 UI 派发、菜单命令、重复、失焦、调整尺寸保留蓝图与销毁释放。原生 PC 建造 814/814、共用战斗 94/94 通过。PC HUD 旧脚本曾因仍断言已替换的旧面板、调用删除的 `SetEnergy`，并在真实加载页尚未退出时点击而失败；已更新为当前准星及实际加载完成条件，131/131 通过。没有放宽生产焦点条件或绕过生产加载流程。

隐藏原生窗口的触控集成块局部提供 focus=true 输入样本，检查后恢复；其中的失焦检查再显式切为 false。浏览器检查使用实际 CDP touch/multitouch 与真实页面点击。各测试窗口错误为 0，不等于整个引擎启动日志无错误。

最终构建为 `outgame-cached-1791948477339 / manifest-c43a4c0b.json`，普通 4206 与 QA 4204 已统一。最终网页 PC 7/7、20:9 手机 44/44、16:9 手机 44/44、4:3 平板 44/44 通过；均未捕获 Lua、着色器或页面运行错误。覆盖实际双指、模拟量移动、按住开火拖瞄、单独释放开火、pinch、取消、菜单滚动/展开、删除/撤销、换格、零件库阻挡、进入试车与返回。关键 PC、手机展开菜单/按住状态及平板菜单截图已查看。滚动中误点的中间夹具失败没有删掉操作检查；最终脚本等待目标位于菜单内并确认实际动作生效。

## 成本与剩余边界

触控绘制在现有 UI 的 VG frame 内完成，没有新建 VG context、离屏纹理、场景或 viewport。字体按上下文首次使用时加载，触控层销毁时清空触点与输入；复用已有保存、武器、建造和驾驶系统。没有为本批增加美术下载。

原 CSS 是 `600 system-ui`，UrhoX 在 Windows 使用可用本机粗体、Web 使用已有 MiSans Bold 作为替代；没有打包 Windows 系统字体。字重替代和 NanoVG 栅格仍可能与浏览器不同，不能称逐像素一致。

本批不是完整迁移完成。复杂触屏拉伸/多选/复制粘贴的全部组合流程、完整 UI 页面视觉对照、MVP/签约演出、转轴镜像盘面、翼面/新版机甲、正式账号云存档刷新恢复和跨设备冲突仍待收尾。真实手机与 M1 的持续帧率、发热和内存尚未验收；桌面模拟横屏触控不作为真机性能结论。未上传、提审或发布 Maker。
