# 原生驾驶迁移（2026-10-05）

本轮交付是赛车/坦克的实际驾驶与机库往返。大厅继续使用 OrbitalHangar.xml；试车环境为可打开的 TrialTrack.xml，两个模式仍由 main.lua / HangarApp 管理。

## 已实现

- 保留源 VehicleSpec、静载分配、油门/反向刹车、转向助力、侧向抓地、悬挂压缩和滚动距离。原生刚体负责接触和积分；控制器不直接改车身姿态来假装行驶。
- 平地单车验证涵盖静止、加速、速度上限、直行、反向刹车、左右坐标约定、转向侧倾、掉落落地和释放。坦克转向超过 180° 时用累积偏航验证，避免 atan2 回绕造成误判。
- 物理和显示分离，60 Hz 固定步长；30 Hz 画面每帧跑两个物理步。卡顿追帧限制为 100 ms，额外时间记录而不积压无限工作。显示插值不反写模拟。
- 轮胎实际转向、旋转、压缩；履带根据第一只负重轮实际行程移动。跟随相机使用 ThirdPersonCamera，在 PostUpdate 更新。
- T/按钮进入与返回，R 原地翻正，N 使用源场地传送位置，Backspace 复原全场。触摸按钮按指针所有权保持，释放、移出、取消和失焦清除控制；原生试车 HUD 与菜单已接入，详见 GUI_MIGRATION.md。
- 试车场从原 TrackView 提取现有几何、canvas 贴图和牌子字体：46 个设施、30 块牌子，141 份模型、4374 顶点、2502 三角形、70 份材质。按材质与 32 m 区块合并固定物件，锥桶与靶板保留动态节点。
- 源场地 400 × 2 × 400 m 地板使用静态三角网格碰撞，保持有限边界。大尺寸凸盒的 GJK 射线法线有噪声，直接造成停车抖动、直线偏移；平面三角形法线避免该问题。坡道/侧倾台保留原旋转碰撞盒，山坡使用闭合凸体。
- 异步加载新场景期间保留旧场景；成功后销毁旧车辆、物理节点、跟随相机、动态反射，释放不再引用的缓存。重复往返检查确认 Track/model-0.mdl 不再驻留。

## 修复的物理适配问题

UrhoX/Bullet 的复合体初始化不能在 DisableMassUpdate 期间直接转为动态质量。该顺序会产生“冲量使速度变化，但物理世界不积分位置”的对象。现在先完成碰撞形状和 EnableMassUpdate，再设置质量，之后才建立刚体适配器。

源是右手坐标，引擎是左手坐标。位置/速度/力镜像 X；四元数镜像 Y/Z；力矩/角速度属于轴向量，也镜像 Y/Z。点力转换为中心力 + 世界空间力臂叉乘，避免旧式 ApplyForce(point) 的位置约定歧义。

## 明确边界

- **不是 Rapier 轨迹完全一致的替换**。UrhoX Lua 不提供逐碰撞形状质量分配、完整原生车辆支撑力 API 或可设置的质心/惯量。当前 Bullet 质心按碰撞形状计算，和源部件质量加权结果不同；逆惯量从单位角冲量响应量测，恢复初始速度后用于接触约束。
- 地面预制车之外，底挂/侧挂悬浮与六台 T5 重载飞行现已完成原生回放和实际关节/触控接线，详见 AIR_DRIVE_MIGRATION.md。原生质心差异通过有界支撑份额适配；不宣称碰撞轨迹完全相同。节足已接入当前源控制器/步态、关节命中盒和触控跳跃，详见 LEG_MIGRATION.md。
- 目标移动、锥桶碰撞与射击已接入 WeaponSystem；12 种武器原生场地命中、血条/闪光/倒下复位、能量与初步射击特效已验证，见 COMBAT_MIGRATION.md。三辆靶车、逐部件损伤、脱落、物理残骸与重生已接入，见 DESTRUCTION_MIGRATION.md；100 米计时与三秒 DPS 已按实际执行原 H5 的边界样例对照。
- 试车灯光使用原太阳方向/强度与源天空 shader，但 IBL 当前来自引擎日间预设；不声称与原版逐像素一致。
- 编辑器可打开 TrialTrack.xml 看环境；还没有试车场的编辑器 Play 接线。没有再次操作用户桌面或重启编辑器；原编辑器崩溃根因仍未确认。
- mobile 档位测试是在当前电脑上运行；不代表骁龙 845 的帧时间、温度或远程资源下载表现。

## 验证与再导入

运行 `tools/migration/verify-native-drive.ps1`（22 项）、`verify-trial.ps1`、`verify-trial.ps1 -Quality mobile`（各 34 项）。JSON 证据在 evidence/native-drive.json、trial-desktop.json、trial-mobile.json；最新渲染截图为 evidence/current-trial.png。大厅生命周期回归 12 项通过。

`export-track.cjs` 只读源项目，写入生成资源 assets/Track。`bake-track.lua` 将场景候选保存到 .tmp/TrialTrack.xml，重新导入时人工核对后再更新正式场景，避免覆盖编辑器已保存的修改。运行时不重新生成环境渲染网格。
