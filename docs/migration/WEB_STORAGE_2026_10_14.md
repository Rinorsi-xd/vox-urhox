# Web 存档迁移：实现与验收边界

基线：H5 分支 `2026-10-13`，提交 `90862445074e7e146da900037979ad97899ecf6c`。只读冻结快照，不读取原仓库实时工作区。目标分支 `codex/h5-2026-10-13`。本批没有修改场景光照。

## 实现

`storage/CloudStorage.lua` 在 Web 有账号身份时，通过 clientCloud BatchGet 恢复记录。恢复完成或明确失败后才创建 HangarApp，避免默认车库或打捞测试库存先覆盖已有账号数据。原生平台保留本地双代存档；验证入口和测试命名空间不连接实际云写入。

两套命名空间为 `vox-garage`、`vox-salvage`，包含各 20 个车位、草稿、当前车位、快捷栏、音乐、画质、匹配资料、剧情进度、教程进度和打捞库存。云 key 前缀为 `vox-save-v1-`，JSON 字符串含 generation、data、deleted、time、capture。恢复前调用现有数据验证器；删除保存明确 tombstone，恢复时同时写两个本地备份，防止旧车辆复活。派生缩略图留在本地缓存。

`storage/CloudSync.lua` 只同步改动记录，同一 key 合并到最新 JSON，不反复上传全部 20 辆车。单个在途写请求，至少间隔 1 秒；滚动窗口最多 60 次/16 MiB，单条上限 4 MiB，启动总读取上限 16 MiB。低于引擎文档的 300 次/48 MB 每分钟限制。草稿防抖和本地双代校验保留；仍持有的存储实例统一更新，切换大厅后旧大厅待保存草稿也能完成。

读取失败、超时、格式错误、账号变化或本地恢复失败后暂停云写入；迟到读取不会覆盖已编辑的车。已发送写入超时/未知错误时不自动推进或重试，防止无取消/CAS 接口的旧请求覆盖新值；后续本地改动保留在队列。收到原请求明确成功后恢复队列。明确 -429 限流等待 5 秒后发送最新值。Stop 和旧请求回调有生命周期保护。

Web 保存提示区分仅本次会话、等待云端确认、云同步暂停和云端已确认。主动保存才弹后续确认，自动草稿不会持续刷提示。未登录本地预览明确提示刷新会丢；退出页面不能保证异步请求完成。

## 未完成

本地浏览器没有平台账号身份；**正式账号保存、刷新、恢复车位及打捞库存仍未验证**。本批未上传、提审或发布。

clientCloud 没有文档保证的客户端批量原子性、CAS 或取消写入。本实现是单会话串行记录同步，不是跨 key 事务；关闭页面发生在 slot、active、draft、stash 多个写入之间时，可能只有部分记录确认。多个设备同时编辑同一账号没有冲突合并保障，不能标记完整云存档收尾。

蓝图二进制压缩/压缩分享码、真实手机/M1、跨设备冲突、长时间离线、恢复后的经济一致性未验收。没有调用未经实测的压缩 API。
