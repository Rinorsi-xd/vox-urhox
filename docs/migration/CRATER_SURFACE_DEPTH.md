# 坠舰陨坑：探照灯外壳穿透修正

2026-10-06。正式战舰机位的远处浅色墙上出现重复黑色短线，源网页没有这些短线。本轮在真实地图中逐份材质隔离，确定来自旋转探照灯外壳 `ship/searchlight_1/ship_searchlight_1`，当前导出为 `mesh-207.mdl`、`material-34.xml`（舰体嵌条）。它不是墙面贴图缺失，也不是曝光问题。

原转换直接使用 WebGL 的斜率深度偏移 `-1`。当前 DX11 下，外壳转到掠视角时会被过大的斜率偏移拉到舰壁前方。只取消该外壳的斜率项，保留原常量项 `-2 / 2^24`，短线消失。探照灯旋转、实际模型位置和材质光照均保留。

转换器根据源节点的 `dyn=searchlight` 层级追踪材质所有者，仅对独占该用途、且原斜率为 `-1` 的材质应用修正，不依赖临时材质编号。静态建筑、地坪、贴片、灯带仍保留原深度策略。早期统一关闭实体斜率的候选导致要塞地坪露出沙地，已经撤回，没有进入最终版本。

## 验证

- `verify-crater-surface-depth.ps1`：26/26，零 Lua、资源和引擎错误。在正式场景冻结动画，五个原网页机位各渲染修正前/后两帧。
- `compare-crater-surface-depth.py`：战舰机位 32,510 个像素通道差超过 1/255；要塞、舰内、甲板和大门四个机位全图最大通道差均为 0。已查看对照图，远墙短线消失，地坪和细灯条没有本轮候选产生的退化。
- `verify-crater-parity.ps1 -Label surface-depth`：233/233。包括原动态姿态、材质绑定和三处正式机位，不代表整图视觉等价。
- `verify-crater-game.ps1`：58/58，实际菜单选图、加载、相机输入回放、驾驶、九区域、返回释放和原试车入口通过。
- 重新运行 `compile-crater.py`，保留同一材质修正；shader 内容未变。本轮没有改引擎或控制用户编辑器。

图像：`evidence/crater-depth-detail.png` 为 H5 / 修正前 / 修正后三列局部对照；`crater-depth-comparison.png` 为五个原生机位；`crater-formal-comparison.png` 已更新为 `surface-depth` 标签。

H5 参考与原生的动态分辨率和动画时刻不同，不能拿局部改善宣称整图逐像素一致。本轮验证后端为 PC DX11，其他后端仍需单独验收。整体 PBR/环境光、阴影和天空输入仍有差异；资源驻留、整图加载与远端下载的限制继续见 `CRATER_RESOURCE_RESIDENCY.md`。
