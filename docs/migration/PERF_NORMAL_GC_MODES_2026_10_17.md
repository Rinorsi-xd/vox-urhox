# 普通 GC 模式对照归档：拒绝发布

日期：2026-10-17。状态：**REJECTED_NOT_SHIP**。

本轮不将 incremental GC 改动合入生产。B 的平均帧间隔较小，但长帧更严重，且两次实际装车、推进的模拟量、目标与通讯状态不同，不能据此宣称改善 FPS，也不能断言 incremental GC 导致卡顿。生产代码未改动，结束本轮 A/B，不追加 BA 重跑。

## 证据与检查方法

- A，显式 generational 对照：[原始目录](evidence/performance-uninstrumented-match-1792190044882/)。
- B，incremental 候选：[原始目录](evidence/performance-uninstrumented-match-1792190291648/)。
- [独立复核 JSON](evidence/normal-gc-modes-2026-10-17/independent-recheck.json)记录源文件 SHA-256、逐项检查、原始边界状态、车辆装配、长帧及环境信息。

两次均用冻结的 `manifest-f881ebb0.json`，经 root 核对 547 个生产脚本 SHA-256 无变化。测试走公开 QA 争夺战入口，持续 W/开火约 30 秒，切换模式后先排除 3 秒稳定期。使用普通浅层 QA 观察器；没有 CDP、分配器查询、停止 GC 或 FramePipeline 详细埋点。

独立复核直接读取有序 `samplesMs`，重算数量、总和、时钟边界、连续性、分位数与阈值；分位数取最近秩 `ceil(N*q)`，阈值为严格大于。A、B 分别通过 **45 项**记录完整性检查，检查名称完整保存在 JSON 中。通过完整性检查不等于 A/B 工作负载等价。

## 装配与实战负载差异

装配以明确字段 `team/slot/player/role/variant/count/bytes/fnv1a32` 规范化排序比较，缺失值统一为空；不会把 JSON 键顺序当成内容差异。真实差异仅在蓝方 slot 2 的 heavy：A 为 variant 1、145 件、5,654 bytes、`c7d66282`；B 为 variant 0、143 件、5,571 bytes、`303815c4`。其余七辆签名一致。FNV 不是加密摘要，且签名仅在选车时采集，后续快照复用该元数据。

两次边界均为八辆存活、满血，部件数量不变，无伤害、死亡或击杀。这次是驾驶接近与开火场景，不能代替近距离交火、破坏、重生验收。root 已目视检查 B 的结束画面：W 驾驶方向有墙/坡，八辆满血；目标横幅和通讯仍存在。

两次初始均为 0 分、站点中立。A 结束蓝方得分 0.4505，B 为 0.141667；B 点占领进度分别 −0.625、−0.456944。两次结束均显示 `takenA` 通讯卡；A 为 speaking=false/jobs=0，B 为 speaking=true/jobs=3，其中 2 个播放中。车辆位置、目标进度、UI/音频时机并不相同，JSON 保留了完整起止姿态与状态。modalOverlay=false 不能解释为没有 HUD 通讯或横幅。

## 污染、恢复与退出

A 的 quiet 锚点 250→251、B 的 248→249 之间没有完整状态行，两个边界都确认 quiet=true。所选、稳定后、结束三个 GC 快照均为 running=true、selected 阶段、previous=generational、wrapper owned、contaminated=false、mutations=0，无显式修改事件。原始日志包含选择与恢复 ACK；两次均恢复原 generational 自动 GC，running=true，无恢复错误。这些是边界观察，不是连续的场景/焦点跟踪。

B 在测量结束后的 seq 264 出现一次 2,203 bytes 的截断 JSON，seq 265 在大厅成功恢复；`duringMeasurement=false`，输入结束为 seq 249。此问题保留在归档中，不影响已完整采集的计时和 GC 输入窗口。没有运行时/HTTP 错误，也不能把这次可恢复问题描述为全窗口损坏。

CPU 环境记录覆盖整个 runner 生命周期，而非仅 30 秒输入：A 为 201,120 ms，编辑器 PID 32168 增加 53.953125 CPU 秒；B 为 201,193 ms，同 PID 增加 52.6875 CPU 秒。PID 8948 两次均增加 0。独立按 PID+StartTime 匹配并重算；未测量其他 OS/GPU 干扰，因此不能认定环境完全相同。

root 确认两次 runner 均 PASS/CLOSED、进程退出码 0，专用浏览器已关闭，4549/4550 HTTP 端口拒绝连接、服务已停。生产代码保持原状。本归档未新开硬件测试、未重跑 BA，也未修改 CURRENT。

## 后续边界

当前证据拒绝发布此 GC 候选，不能给出“已经改善”的结论，也没有定位这些周期长帧的具体执行归属。下一步应只推进可复现、行为等价的针对性优化；最终仍需以骁龙 845 在 TapTap 内的持续 30 FPS、帧时间和温升验收。此轮桌面浏览器对照不能替代该真机验收。
