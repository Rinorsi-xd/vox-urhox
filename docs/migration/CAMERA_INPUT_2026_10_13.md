# 局外相机与 PC 建造输入修正

来源为 `outgame-baseline.json` 中的 H5 分支 `2026-10-13`，提交 `90862445074e7e146da900037979ad97899ecf6c`；使用冻结快照，未修改原仓库。目标分支 `codex/h5-2026-10-13`。

## 根因与行为

- Web `input.mouseMoveWheel` 实际是反号的浏览器像素量。Playwright `wheel(0,100)` 在 Lua 中为 `-100`，此前再乘 100，单次即撞到 60m/2.5m 上限。`controls/Wheel.lua` 统一为 H5 像素：Web 仅反号，本地 SDL 一格转 100px。大厅、涂装、触屏环绕建造共用同一缩放适配。
- 冻结原版 `editor.setViewOnly(false)` 明确只进入第一人称。PC 初次进入按车辆包围盒定位，保留底部四格工作空间，并限制抬升不超建造上界；热重载不重复抬车。取消旧的 Tab 相机切换。
- Tab 从其他工具进入上色，已在上色时切主色/装饰色。普通滚轮累计到 50px 切快捷栏，上色或 Alt+滚轮循环原色及源调色板；Shift/Ctrl+滚轮在第一人称无缩放行为。
- 鼠标锁定后转视角，WASD 飞行，Space/E 上升，Shift 下降，Z 快飞，L 回到车旁，- / = 与 [ / ] 调五档速度。飞行档位保留于当前 App 会话，尚未单独实现跨启动存储。
- 中键只拾取零件和配色，安装朝向继续由命中面决定。C 取色保留当前工具。单帧异常鼠标位移按冻结源尖峰规则过滤；Lua 能看到每帧合计，而源过滤在每个 DOM 事件执行，多事件合帧不保证逐事件一致。
- Web 捕获要等真实 `mouseLocked`，拒绝/冷却请求超时后恢复可点击；Esc、失焦与菜单释放。第一下点击只捕获，不放置零件。
- 大厅/工坊与保存缩略图使用 `PreviewRoom`，沿原观察射线在实体墙前停下，保留 0.35m 余量。复用原 Octree 三角查询，无额外碰撞网格；排除车辆、玻璃、光束、显示零件与移动机械。静止相机复用查询结果。仓库激活时不套用大厅限制；地图预览不使用大厅限制。
