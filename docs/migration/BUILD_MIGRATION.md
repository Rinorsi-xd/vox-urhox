## 使用入口

独立预览点击 **改装战车 · E**，或 `./preview-hangar.ps1 -Build -Quality desktop`。进入后整车抬高，便于编辑底部；回大厅只把展示节点落地，不改写蓝图坐标。编辑器仍打开 `assets/Scenes/OrbitalHangar.xml` 编辑环境；当前嵌入 Play 不承载玩家改装或试车。

- 左键建造/涂装/拆除；桌面按住 300 ms 后每 100 ms 重复一次。
- PC 锁定鼠标后移动视角；右键拆除（上色时不拆除），中键拾取零件与配色，不复制原朝向。触屏保留已有轻点操作、拖动环绕。
- PC 的 Q 选择工具：左键点选/取消，按住移动准星后松开选中两占用格之间的三维范围；右键按住扫过取消，K 选两显式角点之间。触屏环绕仍保留 Shift 屏幕框选；方向键按当前相机水平方向移动所选零件。规则与边界见 `BUILD_SELECTION_2026_10_13.md`。
- R 旋转，Shift+R 反转，Alt+R 倾斜，Alt+Shift+R 反向倾斜，M 镜像，P/X 切换上色/拆除；C 取色并保留当前工具；B 零件库，G 材质；1–0 选择十格快捷栏。
- 普通滚轮累计到原版 50px 阈值后循环非空快捷格；上色时滚轮换颜色，Alt+滚轮在其他工具下也换颜色。Tab 进入上色，已在上色时切主色/装饰色；Shift/Ctrl+滚轮在 PC 第一人称不缩放。
- Ctrl+Z/Y 撤销重做，Ctrl+C/V 复制粘贴，Ctrl+A 全选，Delete 删除选择。
- PageUp/PageDown 有选区时只升降选区，无选区时升降整车；Delete/Backspace 删除选择，无选区时删除当前命中。20 车位、Ctrl+S 保存、草稿延迟 500 ms 保存；蓝图码导入/导出。
- T 试车；返回恢复建造模式。输入蓝图码时屏蔽建造和试车快捷键。
- PC 进入即第一人称；L 对准车辆，WASD 水平飞行，E/Space 上升，Shift 下降，Z 加速，- / = 或 [ / ] 调五档飞行速度。Q 是选择工具；Ctrl+Z 不加速，Shift+R/Shift+左键不下降。第一人称从屏幕中心拾取，桌面左右键支持连续建造/删除。
- 自由相机 Esc 先释放鼠标；再按执行取消粘贴/选择/菜单。菜单、库存、失焦、退出与切场释放捕获和惯性。首次点击重新捕获不编辑；Web 确认浏览器实际锁定后才启用建造，拒绝请求可重试。支持的移动比例为横屏 20:9、16:9 与平板 4:3，详细状态以 `OUTGAME_CURRENT.md` 为准。
- V 或底部“透视”使结构/骨架半透明，保留功能件实体。透视下仍可编辑，新增结构自动采用透视；关闭、进入试车、退出建造会恢复正常材质。F5 与试车返回建造保留透视偏好，主动回首页清除。

## 模块与所有权

| 模块 | 职责 |
|---|---|
| `build/GridRay.lua` | 源 DDA 拾取；整数格、4³ 实体子格及同格多个零件；不使用原生物理射线替代形状规则 |
| `build/Placement.lua` | 相机方向、旋转/倾斜、履带偏移、底挂/侧挂悬浮、节足侧装、镜像占用对齐 |
| `build/BuildEditor.lua` | 纯建造命令、双通道涂装、取样、选择/框选/移动、复制粘贴、预览校验 |
| `build/EditHistory.lua` | 稳定 ID 的增删/涂装事务；镜像与批量操作一次撤销；最多 300 个事务 |
| `parts/Finish.lua` | 从已有模型元数据识别外壳槽，不加载 GPU 模型 |
| `app/BuildSession.lua` | 将命令、输入、当前 VehicleView、预览、UI、存档组合起来 |
| `controls/BuildInput.lua` | 输入必须始于建造区域；UI、离开、取消、焦点丢失、切场释放按住状态 |
| `controls/FreeFlight.lua`、`BuildCamera.lua` | 源坐标自由飞行计算与原生相机/捕获状态分别管理；共享原大厅视口；原生边界镜像 X |
| `render/BuildGhost.lua` | 源模型全息轮廓、占用格、子格命中面、选中框；拥有并释放预览资源 |
| `render/BuildXray.lua` | 两份共享临时材质替换当前车辆的结构槽；保存原材质/阴影，关闭先恢复再释放，不改 Blueprint 或共享材质 |
| `storage/BlueprintStore.lua` | 原生项目/用户隔离 File API、双版本写入恢复、草稿与 20 车位 |
| `storage/BlueprintCode.lua` | FKZC1:j 导出；j 与 z 导入，z 覆盖 raw DEFLATE 的 stored/fixed/dynamic 块；输入与解压大小上限 |
| `build/BlueprintMigration.lua`、`BlueprintDiagnostics.lua` | 原版旧档替换/冲突提示与车辆诊断；不依赖 GUI |
| `build/Inventory.lua` | 原版分类、名称/说明/ID 搜索、方块材质、快捷栏选择/交换规则 |
| `ui/BuildHud.lua`、`InventoryPanel.lua`、`BuildHotbar.lua` | 原版 PC 建造与零件库组合，共享十格快捷栏；绘制拆为独立 NanoVG 模块 |
| `ui/CatalogList.lua`、`OwnedModal.lua` | 按可见行复用列表；释放离开控件树的池化节点及独立弹窗容器 |

VehicleView 按事务受影响 ID 更新；移动保留相同原生节点和关节，增删只处理相应零件。外壳涂装使用每个着色零件拥有的材质，不向全局共享材质写颜色，也不会每换一种颜色新增永久缓存。该私有材质在零件删除时释放。

原版撤销移动会清掉相应的选择状态，本次按原规则保留。原版允许移动/粘贴产生不连通结构，交由车辆诊断提示；放置仍要求连接，地面不接受孤立方块。主件可放而镜像件受阻时，保留主件的成功操作。

## 资源与性能

预览只加载当前用到的已有原生模型。mobile 档最多 16 件完整模型预览，desktop 48 件；大粘贴继续显示占用格，线框最多 4096 格。预览条目减少、换种类、退出建造或切场后释放对应模型引用；不长期保留浏览过的类型。射线/预览刷新上限 30 Hz，位置与选择签名不变时不重新提交几何；全息扫描在 Shader 内执行。

这些是运行时预算，不是骁龙 845 验收结果。原生 `.mdl` 同步获取、首次 Shader 编译仍可能造成帧峰值；没有把本地缓存测试称作边玩边下验收。

## 存档边界

原生客户端使用引擎项目+用户隔离目录，存档不写源 H5 仓库。双版本中优先读取有效且较新的版本；写入中断/损坏时保留上一版。载入先验证候选蓝图，再替换当前车辆。独立验证使用专用命名空间，不读取或覆盖玩家草稿。

原 H5 可直接解码本端导出的普通蓝图码；本端也可解码原 H5 压缩码。空蓝图专门输出 `parts: []`，避免 Lua 空表被编码成对象。缺省外壳色与 JSON null 在两端 Blueprint 中等价。

**WASM 本地 File 存储刷新后会丢失**，见 `engine-docs/recipes/file-storage.md`。跨刷新持久化需要后续 clientCloud 适配，本轮没有假称浏览器云存档已接通。
