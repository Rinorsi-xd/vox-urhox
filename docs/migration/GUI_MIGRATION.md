## 画面设置边界

本机 Runtime 缺少文档与 EmmyLua 列出的 `Zone:GetAutoExposureBias` 等 Plus 曝光绑定。直接写同名属性后没有亮度变化，不能把 Lua 字段回读当成真实渲染效果。已移除无效曝光滑块；保留场景曝光配置，不额外启用直方图 pass。曝光、原版 mist 柔光、胶片颗粒和 AO 切换待后处理适配；当前前向移动管线没有文档支持的可调 GTAO，不能将延迟参数当成可用开关。

零泛光通过 `bloomUEIntensity=0` 实现，保留 Bloom 合成与 ACES，避免同时关掉色调映射。Quality.current 是独立表，不污染预设；画面设置只变更实际支持的选项，不改变装备/武器特效池预算。阴影 1024/2048；反射节能档最大边 384、10Hz，清晰档最大边 960、30Hz。更高档位不代表手机性能已达标。
