# 驾驶声音迁移

来源为冻结 `2026-10-13 / 90862445074e7e146da900037979ad97899ecf6c` 的 `drivingCues.js`、`drivingMix.js` 和 `uiSound.js`。原仓库只读，没有重新生成声音或替换已批准版本。`import-driving-audio.mjs` 记录每份 WAV 的来源、SHA256、字节数及原音量、间隔和变调规则。

## 已接入

- 八份原 WAV，共 1,764,482 字节；履带、推进器和落脚使用原 `driving-03-r2` 的已选版本。
- 五种驾驶循环：轮车怠速/负载、履带、悬浮、推进器。混音取真实速度、输入、现存移动部件、悬浮支持力和推进器输出；零件损毁后随当前车辆重建更新。
- 远处车辆使用原 18 米衰减参考、240 米截止、0.36 音量缩放及摄像机立体声；每种循环只保留最响的远处车辆，不为每辆 AI 新建五个声源。
- 通讯播报时声音降低至 30%；同一循环复用播放实例。最多五个本地循环、五个远端循环、三个机械瞬态实例，退出后全部释放。
- 加载完成前、开场、未捕获鼠标、暂停、失焦、静音和退出停止；传送清掉接触历史。停声同时归零实例音量，避免诊断仍显示旧音量。
- 三个机械瞬态绑定现有控制器真实触地、起跳、失去支撑后落地；初始站立、静止和传送不伪造连续落脚。

原生 `verify-driving-audio.ps1`：450/450，测试窗口 Lua、资源及引擎错误均为 0。包含 84 组冻结 JS 混音输出、原 WAV 解码、绝对 Hz 变调、远处衰减/声像、损毁停声、配音压低、声源上限、暂停/失焦/静音/释放、机械接触桥接，以及生产试车中真实轮车行驶和返回。

网页 `check-driving-audio-web.cjs`：PC 8/8、20:9 横屏手机 6/6，意外运行错误均为 0；构建 `outgame-cached-1791911685015 / manifest-1e6e8933.json`。报告 `evidence/driving-audio-web-{pc,phone-landscape}.json` 包含真实键盘/触屏摇杆驾驶、怠速/负载播放、绝对 Hz、两次进出及重新创建的单一声源。两端试车截图已实际查看；播放状态和截图不代替听感验收或真机性能测试。各端仍有四条引擎 aggregate archive HTTP 404 后备加载。原生完整启动日志仍有历史 DDS/DLL 错误，测试窗口零错误不代表整份启动日志零错误。

## 边界

机械足底层仍是此前迁入的 `LegControl/LegGait`，尚未同步冻结源新版 `mechControl.js` 的完整步态、蹬地腾空、缓冲和镜头反馈。这里接通声音事件，不把它称为新版机甲运动完整迁移。原生机械接触桥接断言使用明确状态输入；生产轮车行驶通过不证明真实机甲跳跃已完成新版对照。

声音总线未迁入 WebAudio 主压缩器，也未实现所有原音频设置和受击/维修混音。局内 HUD、钻头、MVP、打捞、开篇及性能缺口以功能迁移记录为准。
