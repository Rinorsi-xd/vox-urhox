# G1 起飞后分歧：实际同状态单步对照

日期：2026-10-16。正式游戏代码未修改；候选仅存在于隔离快照和本报告证据目录。不得将候选复制到生产后直接称为通过。

## 决策

本轮不合入候选。它修正了已测得的新施力阻尼顺序差异，但未消除自由旋转积分差异，且部分接地、全翼损伤长轨迹误差增加。建议保留当前生产实现，后续继续单独研究真实惯量、自由陀螺响应和接触响应；不通过调整升力、AUTH 或操纵参数掩盖后端差异。

## 实测设计

- Windows Native beta40：`D:/UrhoXEditor/versions/0.9.0-beta.40_20261015.121839.6dc5c357cced/UrhoXRuntime.exe`，headless，真实 Bullet、Vehicle、WingControl。
- H5：`D:/Rino_Project/Vox` 实际 Rapier WASM、Vehicle、`stepWings`，不是公式桩或自行写的物理积分器。
- 输入来自此前实际地面起飞的 Native 轨迹。Feather 取第 133、150、180、210、240、280、300、360、420、480 步；Hawk 取 180、240、360 步。
- 每次新建真实车辆，向两引擎注入相同位置、四元数、线速度、角速度、机翼连续状态和底盘状态。每次只积分一个 1/60 秒。
- 第一批 39 组：有地面，分别不运行控制器、仅运行机翼、运行完整车辆。地面为顶面 y=0 的 1000×2×1000m 箱体，摩擦 0.8。
- 第二批 78 组：移除地面碰撞，再对上述三种模式各加一组初始角速度归零。其余连续状态相同。真实复合碰撞体、质量和惯量保持各引擎原有实现。
- 记录控制器前后与积分后 p/q/lv/av、每次真实力/力矩调用、Native 请求角加速度、H5 `userForce/userTorque`、机翼状态、阻尼及真实逆惯性响应。

这些是物理响应试验，不是 FPS 或 CPU 性能基准。没有渲染、声音、HUD、地图、AI、武器或移动设备测试。原生启动日志中仍有已知天空贴图缺失与 headless UI shader 跳过提示。

## 发现一：空中线性力基本一致，控制器关闭仍有旋转差异

无地面 78 组中，同状态机翼及完整车辆累计线性力仅有浮点舍入量级差异，最大约 0.046N。说明这些输入下的主要后段分歧不能归为“机翼升力没有迁移”。

| Feather 检查点 | 无控制器的单步角速度误差 | 完整车辆的单步角速度误差 |
|---|---:|---:|
| 240 | 0.001223 rad/s | 0.001316 rad/s |
| 280 | 0.009046 rad/s | 0.008998 rad/s |
| 420 | 0.011200 rad/s | 0.011263 rad/s |
| 480 | 0.008213 rad/s | 0.008211 rad/s |

没有任何控制器施力时，差异已经存在。初始角速度归零且不施力时，两端积分后角速度均严格为零。这把其中一部分差异缩到非零转速下的自由角积分及真实质量属性。此试验没有单独证明是哪一种陀螺算法导致，不能把全部误差都归于某一个引擎选项。

有地面的第150步即使不运行控制器，也出现0.104m/s线速、0.0399rad/s角速差；移除地面后分别降至0.000054m/s、0.0000205rad/s。该过渡点存在真实接触差异，不能当作空中公式差异。

## 发现二：新角加速度的本步阻尼顺序不同

旧实现虽然已匹配自由角速度的60Hz衰减，但本步新施加角加速度仍有差异。以 Feather 第280步、无地面、初始角速度归零、仅机翼为例：

- 请求角加速度 `(-3.624657, 10.133145, -6.223369) rad/s²`。
- Native 积分后角速度 `(-0.060411, 0.168886, -0.103723) rad/s`，等于请求值乘 dt。
- Rapier 积分后 `(-0.059812, 0.167211, -0.102702) rad/s`，接近请求值乘 dt 再除以1.01。

隔离候选在 `Body.addFlightAngularAcceleration(alpha, dt)` 中将本步力矩乘 `(1-native.angularDamping)^dt`，机翼及推进器调用时传入 dt。在当前60Hz阻尼映射下，该因子等于 `1/(1+0.6/60)`。未改控制参数、Native重心或惯量；未改无翼路径。

| 无地面同状态试验，13检查点等权 | 原角速度误差均值 | 候选后 |
|---|---:|---:|
| 零初始角速度，仅机翼 | 0.000996187 | 0.000005659 rad/s |
| 零初始角速度，完整车辆 | 0.001094794 | 0.000006572 rad/s |
| 原非零角速度，仅机翼 | 0.002780728 | 0.002753257 rad/s |
| 原非零角速度，完整车辆 | 0.002820192 | 0.002764808 rad/s |

零初始角速度的误差减少约99.4%；非零角速度的总体误差仅小幅改善，符合自由旋转差异仍占主要部分的观察。零角速度试验仍保留原翼状态的配平及bankRate；它验证新施力的映射，不代表一段自然飞行。

## 长轨迹回归与未通过项

重跑此前两机各8段、每段120步的16个空中案例，以及两机各6段、每段480步的地面/损伤案例。对照H5基线和初始状态没有改变。

- 16个空中案例平均姿态误差均改善；部分平均位置误差增加2至21mm。例如 Feather 抬头段0.4054→0.4266m，Hawk 抬头段0.1836→0.1979m。不能表述为所有指标都改善。
- 无翼 raceCar 两段的所有物理及遥测数据保持相同。
- 低速支撑两机末态位置误差仍约6.1mm。

| 地面对照：末态与H5位置误差 | 原实现 | 隔离候选 |
|---|---:|---:|
| Feather 起飞 | 6.901m | 5.832m |
| Hawk 起飞 | 0.955m | 0.916m |
| Feather 落地 | 3.980m | 4.273m |
| Hawk 落地 | 3.912m | 3.979m |
| Feather 单翼损伤 | 0.518m | 0.377m |
| Hawk 单翼损伤 | 0.777m | 0.672m |
| Feather 全翼损伤 | 9.820m | 10.136m |

全翼损伤在第180步重建车辆，前半段轨迹受有翼候选影响；重建后的无翼路径没有直接加入候选逻辑。损伤测试只涵盖零件删除、连接性与重建，不涵盖HP、武器、碎片和死亡事件。

不同damping与非60Hz系统性试验本轮未完成，不能声称候选已支持任意阻尼/步长。由于已有接地损伤回归，本轮冻结隔离结果，未继续扩大调参或落生产。
