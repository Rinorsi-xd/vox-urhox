# 陨坑模型延迟下载

源为冻结 H5 `2026-10-13 / 90862445074e7e146da900037979ad97899ecf6c`。仅修改模型分发路径；原生 UMDL 内容、模型 UUID、几何和材质不变，没有生成替代模型。

## 实现

300 个 `Crater/mesh-N.mdl` 改为 `Crater/mesh-N.bin`，同时更新场景 XML、资源依赖、导出器及检查入口。引擎将 `.mdl` 放入启动阻塞组；`.bin` 可按资源依赖下载。生产 ResourceGate 收到下载就绪后，SceneLoader 再交给原生 Model 加载，不另建下载器，也不修改引擎库。

`node tools/migration/defer-crater-models.cjs --verify` 验证所有模型的身份和哈希，结果为 300 个模型、62,787,290 字节。证据为 `evidence/crater-deferred-models.json`。后续重新导出地图仍输出 `.bin`，历史 `.mdl` 导出夹具由编译器转换。

## 已验证

- 原生资源加载原为 43/43，加入下载停滞/进展检查后为 50/50 通过，报告内错误为 0，证据 `evidence/resource-loading.json`。并发构建曾造成一次约 7098 ms 帧尖峰；独立重跑通过，未提高检查阈值。
- `outgame-cached-1791857489565 / manifest-210847a1.json`：PC、20:9、4:3 Web 各六项生命周期检查通过，运行错误与失败请求均为 0。
- 首屏没有这 300 个模型的网络请求或原生 Model；进入地图才下载，全部到齐后激活；下载中大厅仍可见。
- 暂停模型响应时取消进入，不激活半成品场景；随后重试成功。返回时释放未引用模型，已下载资源可缓存重进。
- 实际检查三种比例的地图截图，地形、建筑、红蓝护盾可见；这只证明地图非空和资源可呈现，不证明与 H5 的渲染一比一一致。

Web 证据为 `evidence/crater-streaming-web-{pc,phone-landscape,tablet}.json`，保留各自构建号、请求清单、截图、日志和帧时间。首屏项目请求为 2510 个 /113,776,373 字节，不含单独下载的引擎；不能与引擎总启动组的文件数混用。

## 边界

这是按地图下载，尚未按地图地理分块流式加载。579 个零件模型仍在启动阻塞组：编辑器幽灵、工坊、蓝图装配和大厅展示都有直接消费者，不能只改扩展名而漏掉等待门禁。

本地首屏仍约 52 秒，地图首次进入仍约一分钟。移动质量档的约 15 秒桌面帧样本不能证明手机温度、M1 性能或持续稳定帧率。原生启动 stderr 的历史 HDR 纹理/themis 错误仍需单独处理，不能称整份原生日志零错误。

弱网入口：`VOX_QA_CASE=pc VOX_QA_WEAK=1` 运行 `tools/migration/check-crater-streaming-web.cjs`。它只从选择地图阶段开始限速至 2 MiB/s、延迟 150 ms，首屏仍使用本地正常网络。完整报告写入 `evidence/crater-streaming-web-pc-weak.json`，不可把该结果描述成全程公网冷启动。

首次弱网测试失败，保留在 `evidence/crater-streaming-web-pc-weak-before-idle-fix.{json,log}`。地图请求合计 237,626,308 字节，按 2 MiB/s 至少需要 113.3 秒；原 SceneLoader 和旧 WASM ResourceGate 各自使用固定 90 秒总时限，下载仍有进展也会取消。修复为 90 秒无进展超时，不放宽原生场景解析/准备的时限。原生检查模拟下载推进 120–160 秒仍成功、停滞 91 秒失败、现代单文件字节进度及旧 WASM 状态轮询，并继续验证真实场景取消与重试。Web 检查新增加载失败立即报告，以及按请求所属的取消代次识别延迟到达的 `ERR_ABORTED`，其他失败继续计错。

修复后 `outgame-cached-1791859893590 / manifest-7f20b22f.json` 的 PC 弱网六项生命周期检查全部 PASS，错误为 0，300 个模型均下载完成。地图首次进入 149,404 ms，缓存重进 12,149 ms。首屏未限速，为 51,214 ms、2511 个项目请求 /113,778,568 字节；地图阶段才应用 150 ms /2 MiB/s。八次受控取消导致的 `ERR_ABORTED` 保留在 `cancelled` 中，没有删除其他失败。大厅/地图约 15 秒样本 P95 分别为 18.89/17.11 ms，仍只代表桌面移动质量档。约 149 秒的首次地图进入不满足快速加载目标。
