# 导弹与武器音效迁移

## 基线

只读来源分支 `2026-10-13`，提交 `90862445074e7e146da900037979ad97899ecf6c`；使用 `outgame-baseline.json` 指向的冻结快照。目标分支 `codex/h5-2026-10-13`。本轮不修改光照，也不加入无尽模式。

## 实际接通

- T3/T4/T5 电磁导弹：2 秒锁定、100–350 米前向深度限制、目标切换与丢锁宽限、部分能量齐射、45 度抬升、开闸、分管发射、移动目标三次曲线、装填与闭闸。
- 导弹炮塔只水平旋转，弹巢绕原版 `weapon.tilt` 俯仰，后坐只作用于弹巢。瓣与弹头挂在弹巢下面，退弹和补弹按原版发射管顺序播放。
- 飞行模型由冻结 `weaponFx.js` 原几何公式离线导出；拖尾、枪口、爆炸和锁定框接到现有战斗呈现，不创建另一套游戏。
- 试车与三种竞技战斗共用伤害环境：排除发射者、队友、复活保护和有护盾保护的基地内车辆；争夺模式的反应堆爆炸按原版 60% 伤害偷分。
- 18 个原版已确认 WAV 样本，合计 1,479,696 字节：加特林/激光开火、转管、狙击蓄力/开火、搜索/锁定/发射/飞行/爆炸、开闸/补弹/闭闸、哑火、命中、能量恢复。
- 声音读取实际模拟状态和每个固定步的事件；飞行声按距离、左右方位及弹丸年龄衰减，多发导弹共用一条飞行声，不按枚数叠加循环声。暂停、开场、失焦、传送与退出停止声音。

原版导弹的视觉俯仰中心 `tilt` 与弹道计算中心 `pivot` 不同。本轮分别保留两条基线合同，没有通过改伤害计算来掩盖视觉偏移。导弹的显示检查对照冻结原版视觉矩阵，其他武器仍检查枪口显示与模拟对齐。

## 移动端预算

导弹模型共用资源与材质，按场景惰性创建有界池：mobile 最多 64 枚可见弹体，desktop 最多 128 枚。超过显示预算只省略模型，模拟和伤害继续执行。拖尾 mobile 每三点取一段；爆炸、烟、发光与电弧保持现有批次上限。退出显式销毁池和专属材质。

音频最多十个一次性播放实例，同一个样本最多三个同时播放；循环实例固定三条。音频采样率按 `Sound:GetFrequency()` 乘 pitch，不把倍率当 Hz。资源在进图门控中按需下载，大厅不创建战斗声音实例。不将这些预算称为真机性能验收。

## 仍未完成

完整原版准星与辅助瞄准、炮塔软障碍范围、钻头、完整驾驶/受击音效和镜头震动仍未完成。新手引导/专属任务、剧情、打捞、MVP、跨刷新存档属于独立的未验收链路，见 `FUNCTIONAL_MIGRATION_2026_10_13.md`。WebAudio 的压缩器和逐总线混音没有逐样复刻，也未录音证明跨引擎听感完全一致。

网页预览的引擎归档仍有四条 HTTP 404 后备加载；报告内意外运行错误与这些请求分别记录。QA 日志在初次载入时可能被引擎截断，测试记录 `truncatedProbes` 并等待后续完整状态，不把截断 JSON 当游戏运行错误。真实手机与 M1 的持续帧率、温度和冷下载仍未验收，不发布或提审。
