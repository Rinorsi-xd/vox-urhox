# 1016 飞机响应校准与 Git 同步

日期：2026-10-16。对照 H5 `2026-10-15@b276064942ae09c0227ec28d4cfda1d5ff006455`；UrhoX 修改前为 `d910f11da5db463818ca31627b91cf155a2ac089`，交付提交以 `git rev-parse 1016` 为准。

## 定位与修复

不是凭“太写实”的描述调整升力参数。原版机翼公式和迁移版原路径的 5,865 项系数、逐帧力/力矩、状态检查通过，但真实 Bullet 与 Rapier 的质量属性不同：

| 飞机 | Native 重心（H5坐标，米） | 实际 Rapier 重心 | Native / Rapier 单位滚转力矩响应 |
|---|---|---|---|
| 隼 hawk | (0, 2.021889, -0.541667) | (0, 1.948671, -1.201014) | 22.25% |
| 羽刃 feather | (0.083333, 2.443500, -0.229167) | (0.022410, 2.048322, -1.208665) | 27.21% |

H5 为每个碰撞体赋零件质量；Native 目前只设整车质量。相同 `.angularDamping=.6` 在两引擎也不等价：Native 一秒后角速度约 0.4，Rapier 约 0.55。

- `FlightResponse` 在首次驱动时重建原版方盒、旋转盒和轮子缓冲圆柱的完整重心与惯量张量，供飞机机翼和推进器计算力矩。张量只计算一次；损伤产生新 Vehicle 时重新计算。
- `Body.addFlightAngularAcceleration` 使用构造时已实测的 Native 逆惯量，将目标角加速度换成 Native 力矩；不会每步调用 require、探测惯量或改写姿态。
- 翼内力臂和辅助控制惯量使用原版重心；`v.com`、Native 质心、碰撞体与其他载具控制保持原有语义。
- 有翼车辆的固定 60Hz 阻尼按 `1-(1+d/60)^(-60)` 转换，匹配 Rapier 的每步衰减。未修改 AUTH、机翼升力、油门键位、相机或模型尺寸。
- 凸包、转轴、无法完整还原质量的混装结构回退原力矩路径；不冒称这些复杂结构已完成质量属性对齐。

实际 beta40 中 `centerOfMass` 写入只会生成 Lua shadow 字段，`GetCenterOfMass()`、真实冲量响应均不变；SetCenterOfMass / SetInertia / SetMassProperties 不存在。本修复没有使用这些无效操作。

## 实际验证

Runtime：Windows Native `0.9.0-beta.40_20261015.121839.6dc5c357cced`。独立进程、headless、真实 Vehicle 和物理积分；修改前从 Git d910f11d 导出完整 scripts，修改后复制完整生产 scripts 并核对散列。H5 使用原仓库实际 Rapier WASM 和 Vehicle，不是运动模拟桩。

| 检查 | 结果 |
|---|---|
| 全生产 Lua 编译 | 534 份通过 |
| 原机翼/推进器公式回退路径 | 5,865 / 5,865 通过；不代替新路径验证 |
| 原版质量张量对真实 Rapier 冲量 | 最大归一化误差 2.59e-6，重心误差小于 3.6e-7 米 |
| Native 角加速度接口 | 72 项，最大角速度误差 5.14e-9 rad/s；含多轴姿态与读缓存 |
| 新阻尼 1 秒 | Native 0.550449848，Rapier 离散公式 0.550449616 |
| 不支持结构回退 | 7 项通过 |
| 无翼 raceCar | 两段共 240 步，修改前后全部物理/遥测字段零差异 |

两架飞机各 8 段，每段 120 个 1/60 秒积分步，共 1,920 个配对状态：中立、持续转向、持续抬头、油门巡航、转向后释放、抬头后释放、反推、2m/s 低速辅助。每段重新设置相同位姿/速度并清空翼控制状态；不会把前段配平带入下一段。

| 与 H5 的误差（16段等权平均） | 修改前 | 修改后 |
|---|---:|---:|
| 平均姿态角误差 | 3.6393° | 0.2547° |
| 平均位置误差 | 0.7066m | 0.1461m |

16 段平均姿态与位置误差均下降。最大单段末态角误差仍为 2.61°，并非两物理引擎逐帧完全等价。Native 实际碰撞重心、自由陀螺运动仍有后端差异；本轮没有虚构原版 COM 速度或强制写位置。

## 证据与边界

精选原始结果、探针与比较脚本归档于 `evidence/flight-1016/`。`source-probe.mjs` 可传入 H5 根目录、Native 输入 JSON、输出 JSON；`compare-motion.mjs` 比较对应 Native 前后及 H5 输出。完整 Native 轨迹含非飞机负控。

没有地图接触、地面起飞、空中损伤重建、实机操控感、渲染或手机性能验收。日志仍有既有天空贴图缺失和 headless UI shader 提示。本次结果不能证明骁龙845/TapTap持续30FPS，也不能以旧4453或4461缓存包检验新飞机修复；Web 同步部门必须从新提交重新构建。
