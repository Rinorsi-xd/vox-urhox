# 转轴、履带碰撞与炮塔限位迁移

## 实际接入

- 原转轴负载、结构卡死、5° 扫描、嵌套顺序与独立拥有关系。连块负载和无缝表面按拥有关系分组。
- 跟随准星、匀速旋转、F 步进 90°；有限范围摆动、0.4s 卡死回弹、左侧安装反向和嵌套姿态。
- 武器、轮子、悬浮器、推进器、连块网格与贴纸联动；显示插值、原生 compound 碰撞、射线、逐块受伤和脱落位置同步。
- 建造页原三模式 HUD、蓝色负载框与阻挡颜色；1/2/3 换模式，镜像替换保持 ID，一次撤销事务。
- 试车、静止靶车、竞技、剧情与打捞共用控制；受损重建保留角度，视觉节点先恢复蓝图坐标，避免重复旋转漂移。
- F 输入保留到首次固定物理步，同帧多个物理步只消费一次；暂停与退出清除待处理输入。
- 四种直立履带使用冻结源 Float32 凸包，保留圆弧/斜坡端面；悬挂负责负重轮轴线下方，侧装/倒装和碎片保留原方盒规则。真实原生碰撞为 convex hull，受击 sensor 保留源完整占格范围。
- 炮管采样与 5° yaw / 3° pitch 软限制；自身安装格和其他武器不挡路，只检查同一转轴上的零件。受挡时抬炮管或停在边界，超过 45° 的障碍方向不能穿越；建造诊断显示原警告。
- 炮塔限位按蓝图、位置、旋转及拥有关系缓存，障碍删除/重装时失效。无转轴车辆跳过动画，静止角度不重复改原生碰撞，连块旋转不重建几何。

## 网页修复

冷下载时换转轴模式曾触发 `Model requested before download readiness`。三种模式的原模型不同，先前仅下载当前型号；现在零件依赖门禁同时准备该转轴的三种模式，支持即时切换及撤销重做。没有把全部零件重新加入启动阻塞组。

QA 入口改为 Insert，避开游戏 F5 重载。六件装配经过真实资源门禁、生产蓝图导入、建造、试车和返回；组合键保持跨帧按下，返回等待完整转场并恢复原建造状态。探针只由 4204 附加，普通 4206 main 无探针。
