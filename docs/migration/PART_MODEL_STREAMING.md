# 零件模型按需下载（2026-10-13）

## 基线与构建

原 H5 为只读冻结分支 `2026-10-13`、提交 `90862445074e7e146da900037979ad97899ecf6c`，快照位于 `.tmp/outgame-source-2026-10-12T21-18-23-463Z`。迁移目标为 `codex/h5-2026-10-13`。本轮没有提交、推送或发布 Maker。

浏览器取证构建为 `outgame-cached-1791872635226 / manifest-52c71fd8.json`。使用本机下载过的引擎镜像、Windows RTX 5060 Ti、Chrome ANGLE D3D11；模拟触控不是手机真机。

## 实现

579 个 `Parts/Models/*.mdl` 改为 `.bin`，UMDL 字节与 UUID 保留，合计 55,432,424 字节（52.9 MiB）。316 个 rig、依赖索引和导出器同步使用新路径。发布清单确认这些模型都不在 `boot` 或 `#blocking`；`cache:GetResource('Model', path)` 在下载就绪后仍使用引擎原生模型读取器。

`PartAssets.Model` 检查本地文件存在后才解码，防止未下载文件污染负缓存。门禁仍使用引擎下载、缓存和组取消；旧 WASM 缺少完成回调时，只轮询尚未完成的组，不自建下载服务。

消费者分别预取依赖：启动/热重载、主页换车和导入、车位删除后的替代车、打捞车库与大厅切换、改装草稿恢复、选中零件/镜像/粘贴幽灵、目录当前页、车位缩略图、试车车辆与靶车。工坊详情继续分帧装配，模型门禁在装配前完成。

等待期间不执行换车的存储操作，不下沉当前战车；进入改装或试车不能强制提交尚未就绪的换车。离开页面、切换类型、取消或销毁均撤销本观察者，过期回调不能修改新页面。幽灵加载失败不会逐帧重试，玩家再次尝试放置才重试。

压力检查发现退出改装会重建主页、丢失工坊选择。冻结 H5 的 Home/Workshop 实例会保留选择及筛选，迁移端已保存纯数据字段，在主页重建时恢复，不保留旧控件、预览节点或图片句柄。离开详情仍按原版返回全部页。

打捞车库“新建底盘”保留原打捞页面流程，不套用竞技主页的新车回调。

## 测量边界

构建启动日志为 3022 个待下载文件 / 116.5 MB（含引擎），当前赛车的 3.9 MiB 模型在其后按需请求。52.9 MiB 是移出阻塞组的模型体积，不是整个可操作首屏减少的流量，也不是显存节省。

| 浏览器视口 | 本地启动至可操作检查点 | 往返前大厅 P95 | 往返后大厅 P95 |
|---|---:|---:|---:|
| PC 1920×1080，DPR 1 | 48.3 s | 20.27 ms | 19.82 ms |
| 20:9 840×378，DPR 3 | 46.7 s | 19.62 ms | 20.02 ms |
| 4:3 1024×768，DPR 2 | 46.3 s | 19.64 ms | 19.62 ms |

每次帧时间采样约五秒，使用同一移动质量档；首屏时间包含脚本等待和观察点延迟，不是首次像素计时。浏览器禁用 HTTP 缓存，引擎资源走本机镜像，但 GPU shader 缓存未清空。这些结果不能代表公网冷下载或 shader 真正冷编译。

往返前后引擎 Model 统计保持相同：PC 18,033,902 字节，20:9/4:3 17,969,173 字节。普通资源统计也保持相同，但 Texture2D 统计仍有已知缺口，不是总显存或进程总内存。Lua 堆没有持续/强制 GC 验收，不据这四轮证明没有泄漏。

大厅采样时约 1170–1224 批次、177–180 万 primitives。反射及动态物件会影响单帧计数；这是引擎统计，不是唯一网格面数。仍有较高绘制成本，不能宣称完成手机性能优化。

本轮未验证真实手机或 M1、30 分钟温度与帧率、多车混战、Web 跨刷新存档、完整包首次公网下载、所有 311 种零件逐个冷下载。页面字体、模糊、灯光、反射和完整视觉复刻仍以 `OUTGAME_CURRENT.md` 的未完成项为准。
