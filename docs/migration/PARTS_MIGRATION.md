## 武器与车辆描述的约定

- `source-weapon-fixtures.mjs` 只读导入源 `weaponStats` / `WeaponSystem`。武器平衡参数写入 `assets/Combat/Weapons.json`，包含源文件 SHA256；回放文件留在工具目录，正常游戏包不加载。
- `export-parts.cjs --apply` 统一生成模型、rig、Catalog、装配元数据和 `assets/Drive/Geometry.json`。`source-vehicle-fixtures.mjs` 只生成验收基准，不再静默更新正式资源。执行 `node tools/migration/verify-source-assets.mjs` 可检测源变更、生成物哈希差异、缺失模型和缩略图不一致。
- 武器组/枪管索引在 Lua 中为 **1-based**，shot 事件的 barrel 也一样。蓝图旋转 ID 仍为源 ABI **0..23**。不能把两种索引约定混用。
- 数学和模拟保存源右手坐标，距离为米；`WeaponLoadout` 把格单位挂点转换成车身米单位，`WeaponView` 通过 `PartRig` 转成 UrhoX 坐标。
- `WeaponSystem:Step(1/60,state,env)` 使用注入的 `castRay` 和 `hit`；后坐通过 body adapter 回调。纯逻辑对照环境使用解析平面；TrialSession 已额外连接真实地图、原生刚体后坐、靶板伤害与靶车逐部件损伤。
- 覆盖同类超配限速、停火冷却、能量离线恢复、超射界禁发、多管轮射、旋转炮口、射程衰减、狙击穿透参数和弹丸扫掠。穿透到下一零件由 CarUnit 的实体掩码步进查找处理。
- 参数资源在应用初始化时读取；本轮没有给战斗状态增加通用热替换，修改结构性模拟代码后重启预览。
