# 开火点光与 T5 狙击余迹

当前正式 TrialSession 的 CombatEffects 接入原 H5 `three/src/drive/effects.js` 的共享瞬时点光，以及 `weaponFx.js` 中 T5 狙击电离余迹的后续电弧。源目录保持只读，未生成新美术素材。

## 实现

- `scripts/render/CombatLight.lua`：每场景一盏 22 m、无阴影点光。机枪、激光、狙击枪口、激光/狙击延迟命中和爆炸沿用原强度、颜色、指数衰减、弱光请求抑制及机枪位置平滑。普通机枪命中、干射、破坏和装备上线不额外发光。清空时立即关闭，退出时销毁。
- `scripts/render/CombatEffects.lua`：T5 狙击余迹保留 0.75 秒，前 80% 生命周期按原间隔生成二次电弧；余迹先于光束/命中更新。电弧和螺旋复用原无噪声 WeaponFx/Ribbon SurfaceShader，弹道本身继续使用带噪声版本。
- 五个基础几何批次之外按需创建一个电弧批次；desktop 上限 2048 段、mobile 性能配置 640 段。余迹最多 32 条，电弧最多 64 条。压力下允许视觉截断，不修改武器伤害或射线结果。

没有新增竖屏布局或触屏操作。mobile 是 PC Runtime 上的性能预算配置，并非手机验收。

## 验证

执行 `verify-combat-presentation.ps1`（可加 `-Quality mobile`）会运行未修改的原 H5 Effects/WeaponFx 类，产生 19 组、305 个状态。固定随机值 0.5 后比较光源位置、颜色、强度、衰减、触发抑制与存活电弧端点/年龄/寿命/宽度。它验证公式及调度，不证明随机分布和所有画面完全相同。原生池使用末项交换删除，比较按一对一匹配，不能按数组顺序判定。

当前 desktop/mobile 各 **806/806**；既有实际战斗测试各 **94/94**，含超额事件几何预算、生命周期、PC 接管点击抑制、持续开火与释放。旧测试引用已移除的触屏 onPointerUp 曾失败；已按现有 DrivePointer 输入适配器更新，无需恢复废弃 GUI。地图入口/视角/九区域/退出复测 **58/58**。上述报告均零验证期 Lua/资源/引擎错误。

真实车辆开火后冻结模拟和相机，只关闭点光，分别截图。`compare-combat-presentation.py` 比较排除枪口和 HUD 的路面区域：desktop 有 53,234 个像素差大于 2/255，最大差 69/255；mobile 配置为 53,248 个、69/255。见 `evidence/combat-presentation-comparison.png` 和 `combat-presentation-pixels.json`。这是原生光源开关对照，不是 H5/原生全画面一致性证明。

本次观测的 PC shader 变体补入资源包并保留既有日志/退役排除清单，当前 534 文件、4,165,703 字节，源码/引擎/二进制指纹通过。此次未重新隔离本机缓存测试冷启动，不能声称全部新路径零冷编译。

## 仍有差异

原生近距离点光衰减与 Three 的反平方衰减不同，不能由参数对齐推出逐像素亮度相等。部分闪光尺寸/色彩、抛壳、声音等表现仍需核对。碎片和重力火花的零高度假设已在后续修正，原地形采样、轨迹及内存释放证据见 CRATER_COMBAT_GROUND.md。整个地图的 PBR、阴影及天空输入差异见 CRATER_VISUAL_PARITY.md。真实骁龙 845 持续性能、远端弱网下载均未验收。
